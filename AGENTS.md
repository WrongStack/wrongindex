# Agent instructions for WrongIndex

Read `docs/plan/README.md` and the documents it links before changing behavior. The plan's invariants (INV-01..INV-14) and ADRs are binding unless an ADR update says otherwise.

## Hard rules

- Never write to a WrongStack `index.db` outside a disposable fixture copy until ownership (WI-109) and profile admission gates exist. The inspector must stay read-only.
- Never run project scripts, builds, macros, or package hooks while indexing or discovering files.
- Never claim indexing, watching, WrongStack integration, or native parity that is not implemented and tested. Report PASS / FAIL / NOT RUN / UNSUPPORTED separately.
- Never put credentials in arguments, logs, responses, or the WebView.
- Contract fixtures (`contracts/`, `tests/fixtures/oracle/`) are generated by `scripts/`; do not hand-edit them. Regenerate from a recorded WrongStack baseline and keep the provenance fields.
- Do not silently change fixtures to make a parity test pass; record the difference.
- Do not add dependencies without pinning exact versions in the workspace `Cargo.toml`.

## Checks before reporting work as done

```powershell
cargo fmt --all -- --check
cargo clippy --workspace --all-targets --locked -- -D warnings
cargo test --workspace --locked
```

Timing-sensitive integration tests (`crates/wrongindexd/tests`) must pass five consecutive runs for initial acceptance of a change touching IPC or lifecycle.

## Conventions

- Rust edition 2024, toolchain pinned in `rust-toolchain.toml`.
- Blocking SQLite work runs on the blocking pool, never on the async reactor.
- Errors crossing IPC use `wrongindex_contracts::ErrorCode`; add a code rather than overloading `INTERNAL`.
- UI text and docs are English.
- Update `docs/status.md` with task IDs, commands, and results at the end of each milestone session.
